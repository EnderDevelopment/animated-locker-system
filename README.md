# Animated Locker System

A versatile animated locker system for FiveM servers.

## Features

- Multiple locker pages for organizing items
- Animated GUI for a better user experience

## Requirements

- FiveM server
- ESX Framework

## Installation

1. Download the script
2. Add the script to your resources folder
3. Add `start animatedlockersystem` to your server.cfg

## Usage

1. Place the locker at desired locations using the Config.LockerPositions table
2. Customize the locker pages and default items in the Config.LockerPages and Config.DefaultItems tables
3. Start the script and enjoy your new animated locker system

## Configuration

The script can be configured using the `config.lua` file. You can customize the locker positions, pages, and default items.
